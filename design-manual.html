Visuelles System für Website, Lebenslauf, Landingpages und alle weiteren Anwendungen. Grundidee: Mid-Century-Grafik trifft Gegenwart — die Formsprache von Jazz-Plattencovern, übersetzt in ein modernes, schnelles Marketing-Auftreten. Anspruchsvoll in der Substanz, mühelos im Auftritt.

Farben

Vier Farben tragen das System. Orange ist die Signalfarbe und wird sparsam eingesetzt — als Akzent, nie als Fläche über größere Bereiche. Teal ist die zweite Stimme, Papier und Tinte bilden das Grundgerüst.

Typografie

Zwei Schriften, mehr nicht. Anton für alles Laute, Archivo für alles Lesbare. Auf Mono-Schriften wurde bewusst verzichtet — Labels entstehen durch gesperrte Archivo-Versalien.

Icons

Handgebaute SVGs im Cut-Paper-Stil: geometrische Grundformen, keine Outlines, keine Verläufe, maximal drei Farben pro Icon. Jedes Icon steht für ein Thema und wird nur dort verwendet.

Sprache

Der Ton ist Teil des Designs: direkt, konkret, ohne Marketing-Weichspüler. Ehrlichkeit ist das Verkaufsargument — auch wenn sie Geschäft kosten könnte.

So klingt es

„Ich optimiere auf Deckungsbeitrag, nicht auf Schaufenster-KPIs."

„Auch wenn das Ergebnis ist, dass Sie mich nicht brauchen."

„Unter 3.000 € Mediabudget melde ich mich nicht als Dienstleister an."

„Wer Ihnen etwas anderes verspricht, verkauft Zufall als Können."

So nicht

„Wir maximieren Ihren digitalen Erfolg."

„Innovative Lösungen für Ihr Business."

„Lassen Sie uns gemeinsam durchstarten!"

Superlative, Ausrufezeichen, Emoji-Ketten, Agentur-Wir.

Anrede: Sie. Perspektive: Ich (kein Agentur-Wir — es gibt nur mich). Zahlen immer mit Quelle. Keine Behauptung ohne Beleg.

Was das System kaputt macht

  • Eine dritte Schrift einführen — besonders Serifen oder Mono.
  • Orange großflächig einsetzen. Es ist Signal, nicht Fläche.
  • Runde Ecken, Schlagschatten, Farbverläufe auf Flächen.
  • Stockfotos. Es gibt echte Creatives und echte Porträts.
  • Icons in anderen Stilen (Outline-Icons, Emoji, Icon-Fonts).
  • Mehr als zwei dunkle Blöcke pro Seite — der Kontrast lebt von Seltenheit.
  • Marketing-Floskeln. Sie zerstören die Glaubwürdigkeit schneller als jedes Layout.
